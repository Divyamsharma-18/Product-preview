# 🧴 Product Preview Card — *Where Minimalism Meets Luxury Skincare Vibes*

A **Product Preview Card** so classy that it looks like it belongs on a *$200 moisturiser website* promoted by influencers who whisper in their skincare routines 😌💅

Live Demo → **[https://producreview.netlify.app/](https://producreview.netlify.app/)**

---

## 🛍️ What’s This Project?

This is a **Frontend Mentor challenge** focused on building a **responsive product card** that:

* Shows product image
* Highlights description + fragrance + sizing
* Displays pricing (both *rich-person price* and *discounted student-survival price*)
* Includes an **Add to Cart** button that emotionally whispers:

  > “Treat yourself… you deserve it.” 🍃

---

## ✨ Features

* 🌱 **Clean, neutral, soft aesthetic**
* 🧼 Typography that says “I shop at Muji”
* 🥹 Two-price display (because deals = happiness)
* 🛒 Styled **Add to Cart** button with hover effects
* 📱 **Fully responsive** — looks good on every device (even your old Android)
